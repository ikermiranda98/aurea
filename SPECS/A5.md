# A5 — Tasks programadas + links + programas (detección)

## 1. Propósito

Portar la agenda del motor (tasks de arranque/parada con reloj de PC), el registro de enlaces IBKR/MT5 (persistencia, recarga al arrancar, validación de host AE-005) y la detección de programas en Windows (TWS/MT5 vía registro + `tasklist`), más el stub de conexión IB hacia `crates/tws`. Es la capa que hace que el motor sobreviva reinicios y encuentre los programas del usuario.

## 2. Comportamiento exacto observado en el código TS

### 2.1 Tasks (`trading.ts:2568-2843`)

- `nextAtTime(atTime, now)` (`:2576-2588`): regex `^(\d{1,2}):(\d{2})$`; `hour > 23 || minute > 59` → null; construye el instante como **fecha local** (`new Date(y,m,d,h,min)`) y si ya pasó, al día siguiente **como fecha local +1 día** (nunca `+24 h`; así los cambios de hora no desplazan el cierre).
- `taskAdd(input)` (`:2590-2644`):
  - `delayMinutes` y `atTime` son mutuamente excluyentes; ninguno → error; `delayMinutes` debe ser finito y > 0.
  - `runAt = now + delayMinutes*60_000` o `nextAtTime`.
  - `systemIDs` se deduplican; cada uno debe existir en el pool o `SystemNotFoundError`.
  - `TaskID` = `"trd_" + ascending()`; insert con `status:"pending"`, `resolved_at:null`; log `trading.log.task.scheduled`; `refreshTasks`.
- `taskCancel(id)` (`:2646-2661`): sólo `pending`; si no existe → `TaskNotFoundError`; si no está pendiente → `InvalidTaskError("Only pending tasks can be cancelled.")`; pone `cancelled` + `resolved_at`.
- `reconcileAtBoot()` (`:2664-2689`): tasks `pending` con `run_at <= now` → `missed` (nunca se disparan tarde en ráfaga); log `trading.log.task.overdue`.
- `refreshTasks` (`:2557-2566`): `orderBy(time_created desc, run_at desc).limit(50)`.
- `tick` (`:2784-2843`):
  1. `rentaBucle()` (arrendamiento `bucle-motor`, 30 s, `:2739-2765`); si no lo tiene, el tick duerme.
  2. Primer tick con lease: `ponerEnMarcha` (conecta el socket primario; **no abre nada**).
  3. `revisarProgramas`, ingesta de bots, `sondear`, `muestrearEquity`, `sincronizarCuentas`, `revalidarCuentaActiva`.
  4. Re-renta; lee tasks vencidas; por cada fila y por cada sistema: `pasoDeTarea` con **re-renta entre pasos**; si se pierde el lease, la fila queda `pending` para el nuevo dueño.
  5. `status = fallos > 0 ? "failed" : "ran"`, `resolved_at = now`; log `task.failed_steps`.
- `pasoDeTarea(kind,id)` (`:2769-2782`): `start-systems` → `arrancarNucleo(id,"task").ok`; `stop-systems` → `pararBot(id,"task").stopped`; `SystemNotFound` se loguea, no lanza.
- `rentaBucle` (`:2739-2765`): insert si no hay fila o es del mismo `TITULAR_BUCLE` (`proceso-<pid>-<rand>`); si el dueño es otro y `now - time_updated <= 30 s` → `false`; si está callado, `UPDATE ... WHERE id=? AND value=?` (optimista) y gana si afecta.
- Arranque (`bootClaim`, `:3784-3812`): insert `onConflictDoNothing().returning()`; si no inserta y el dueño es otro: si `now - time_updated > 30 s` intenta el `UPDATE` condicionado; si también pierde, log "otro proceso ganó".

### 2.2 Enlaces IBKR

- `Opciones` (`host`, `port`) por build; defecto `127.0.0.1:7497` (`:781-782`). El enlace primario es `host:port` (`:917`, `:1421`).
- `enlaceNueva(id, host, port, etiqueta, cliente, bloqueado)` (`:934-951`): `IBApiNext` con `reconnectInterval: 5_000` y `connectionWatchdogInterval: 15`; `bloqueado` (AE-005) nunca conecta.
- `siguienteClienteEnlace = 71` (`:921`); cada enlace nuevo toma el siguiente (`:1398-1399`), lejos de los CLIENT_ID de los bots.
- `enlazar(host, port, etiqueta, persistir)` (`:1395-1414`): valida `hostTwsPermitido`; `id = host:port`; insert en `trading_link` si `persistir`; `ib.connect(cliente)`; log.
- `hostTwsPermitido` (`:546-553`): trim, no vacío, ≤ 80, `isIP` 4 → `esIpv4Permitida` (127/8, 10/8, 172.16/12, 192.168/16); `isIP` 6 → `esIpv6Permitida` (loopback `::1`, `fc00::/7`, o `::ffff:` mapeado a IPv4 permitida). Hostnames, `fe80::1`, `::`, `0.0.0.0`, ceros a la izquierda → rechazo. Mensaje `MENSAJE_HOST_TWS` (`:475-476`).
- `linkAdd(input)` (`:3954-4003`):
  - `broker` por defecto `ibkr`; `nt` → rechazo honesto.
  - MT5: requiere `mt5Login` (safe int ≥ 1) y `mt5Server` (no vacío, sin `@`, ≤ 80), y **no** `host`/`port`; `id = mt5-<login>@<server>`; duplicado → error.
  - IBKR: requiere `port` (1-65535); el puerto **7496** (live) exige `live: true`; `host` se trimmea y valida; si `id === clavePrimario` → **connect del primario y no persiste nada** (`:3995-3999`); duplicado → error.
- Recarga al arranque (`:4181-4204`): por fila, saltando el primario; MT5 sin `login/server` → warning y no recarga; IBKR con host no permitido → enlace **bloqueado** (nunca conecta); puerto inválido → no recarga.
- `linkRemove(linkID)` (`:4223-4269`): el primario nunca se puede quitar; si el enlace no está en memoria pero la fila sí → borra fila + cuentas; si está: mata el bridge MT5 o desconecta el socket, borra fila, olvida las cuentas recordadas y, si la cuenta activa desaparece de todos los enlaces, borra `cuenta_activa`. Devuelve los enlaces restantes.
- `asociarCuentas` (`:1252-1389`): por cada enlace, streams de `connectionState`, `accountSummary`, `accountUpdates`, PnL por cuenta y posiciones (sólo en watches).

### 2.3 Enlaces MT5

- `enlaceMt5Nueva` (`:968-982`); `enlazarMT5` (`:4009-4024`): `id = mt5-<login>@<server>`, insert con `host:"", port:0`, arranca el puente (`arrancarPuenteMT5`, `:4029-4098`) con `python -c PUENTE_PY --login <login> --server <server> --desfase <datosBots>\desfase-<login>.json`, `PYTHONPATH` opcional.
- Puente: lee `cuenta`/`estado`/`bot`/`resultado`; al salir, rechaza los `esperando` y reintenta a los 5 s; `apagadoMT5` corta el reintento.

- `INSTALACION`: TWS `^Trader Workstation/i`, MT5 `MetaTrader 5/i` (`:30-33`).

### 2.5 Detecciones

- `puertoAbierto(host,port)` (`:557-569`): valida host, `createConnection`, timeout **1,5 s**; conecta → true; error/timeout → false. Sin handshake.
- `ibkrDetect({host?,port?})` (`:4281-4305`): valida host y puerto (1-65535); candidatos = `PUERTOS_IBKR` (`7497 paper`, `7496 live`, `:462-465`) o el único dado; golpea en paralelo; devuelve `{host,port,live,open}`.
- `mt5Detect(probe?)` (`:4307-4341`): `leerCuentasDisco(%APPDATA%\MetaQuotes\Terminal)`; si `probe !== true` sólo disco; si `probe`, usa el puente MT5 conectado o lanza `sondearCuenta(pythonMT5())` (60 s, puede abrir el terminal); ordena `active` primero y login ascendente.
- `leerCuentasDisco` (`mt5.ts:220-226`): subcarpetas de 32 hex (`/^[0-9A-F]{32}$/`); por terminal, `config/common.ini` `[Common] Login/Server` (activo) + los **7 logs más recientes** `YYYYMMDD.log`; regex `AUTORIZACION = /'(\d+)':\s*authorized on (\S+) through/g` (`:170`) y `APERTURA = /new (?:\S+ )?account '(\d+)' opened on (\S+)/g` (`:174`); decodifica UTF-16LE con BOM o UTF-8 (`:161-166`).
- `poolSelect(dir)` (`:3751-3776`): rechaza carpeta vacía, rechaza si algún bot corre, persiste `carpeta-sistemas`, recarga el pool en el acto.
- `clientId` del motor (`:789-815`): build → `TRADING_CLIENT_ID` (1000-9999) → `trading_meta.client_id` → genera `1000 + rand(9000)` y lo persiste → si la DB falla, `CLIENT_ID = 30` (`:742`).

### 2.6 Stub de `registro-ib` hacia `crates/tws`

- `registro-ib.ts` (30 líneas): `CLIENTE_OCUPADO = 326`; `conexionIb(opciones, alOcupado)` construye `IBApiNext` con un `logger` que sólo pasa el aviso `Code: 326` (regex `OCUPADO`) al callback; `logLevel = LogLevel.INFO`. Motivo: la librería sólo lo emite por el logger, nunca por `errorSubject`.
- En Aurea este módulo desaparece: `crates/tws` debe exponer el evento "client id ocupado" (326) de forma equivalente y llamar a `clienteOcupado` (`trading.ts:956-966`).

## 3. Edge cases y condiciones de error

- **AE-005**: host público o hostname → `MENSAJE_HOST_TWS` en `linkAdd`, `ibkrDetect` y recarga (la recarga marca el enlace bloqueado en vez de fallar el arranque).
- **Puerto 7496 sin `live:true`** → rechazo (consentimiento de leer real).
- **Registro propio (`host:port` del primario)** → connect del panel, sin fila (un registro duplicado haría que el panel quedara "registrado" sin poder quitarlo).
- **MT5 server con `@`** → rechazo (rompería el id).
- **Task con `atTime` ya pasado** → mañana, en hora local (no +24 h).
- **Task vencida con la app cerrada** → `missed`, nunca se dispara.
- **Lease `bucle-motor`**: dos procesos no ejecutan deberes a la vez; un dueño callado > 30 s pierde el lease; perderlo a mitad de una fila de tasks deja el resto pendiente (los pasos son idempotentes: un bot arrancado reporta `ok`).
- **`taskCancel` de una tarea ya resuelta** → error; de una inexistente → `TaskNotFound`.
- **`reg query` vacío o con entradas sin `InstallLocation`** → se usa `DisplayIcon`; si no hay ruta válida → `falta`.
- **`localizar` en no-Windows** → null.
- **Detección MT5 sin terminal** → disco únicamente; `probe` puede abrir el terminal (por eso va detrás del botón del asistente).
- **`terminal_abierto()` no legible** → `None` y no se adjunta (no abrir MT5 a ciegas).
- **`clientIdEnUso` al activar un bot** → adopta en vez de spawnear (evita el 326).
- **Recarga de enlace con puerto inválido** → no recarga (fila huérfana).

## 4. Mapeo TS→Rust

- **Tasks**: `crates/trading/src/tasks.rs`; `tokio::time::interval` de 5 s para el `tick` del motor; el lease en `trading_meta` con `UPDATE ... WHERE id=? AND value=?` y `changes() > 0`; `next_at_time` con `chrono` (construcción en hora local, +1 día con `checked_add_days`).
- **Enlaces**: `crates/trading/src/links.rs`; el `IBApiNext` se sustituye por `crates/tws` (D1/D2) detrás de un trait `TwSConnection` (connect/disconnect/connection_state/account_summary/account_updates/positions/open_orders/place_order/cancel_order/contract_details/execution_details). `host_tws_permitido` → parser `IpAddr` + rangos; sin `isIP` de Node: usar `ToSocketAddrs` no (resuelve DNS); usar `parse::<IpAddr>()`.
- **Programas**: `crates/trading/src/programs.rs`; `reg query` y `tasklist` con `tokio::process::Command` y `CREATE_NO_WINDOW`; `abrir` con `Command::spawn` + `creation_flags(DETACHED_PROCESS)` + `stdio(null)`. `CARGA_PROGRAMA_MS` → `Duration::from_secs(120)`.
- **MT5 disco**: `crates/trading/src/mt5/disk.rs`; lectura UTF-16LE con BOM (`encoding_rs` o conversión manual) y regex con `regex` crate; `leer_cuentas_disco` tal cual.
- **Arrendamiento multi-proceso**: `rusqlite` con `busy_timeout`; `INSERT OR IGNORE ... RETURNING` (SQLite ≥ 3.35; bundled 0.32 lo soporta).
- **Efecto `Effect.fn`/`Layer`** → un `Engine` con campos `Arc<...>`; los streams IB → `tokio::sync::mpsc` consumido por tareas.
